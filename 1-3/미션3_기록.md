# 미션 3 기록

## 받은 피드백을 읽기 전 확인 기록

아래 기록은 받은_피드백.md를 읽기 전에 남겼다. 동작은 사용자가 Chrome에서 직접 실행하고 결과를 알려 주었다. AI의 브라우저 자동 조작은 연결 오류로 실행하지 못했다.

| 확인할 기준 | 해 본 행동 | 실제 결과 | 확인 범위 |
|---|---|---|---|
| 외부 파일이나 로그인 없이 HTML 한 장으로 열린다 | 제공된 HTML 파일을 Chrome에서 열고 영화 추가·이동·초기화를 사용했다. | 별도 파일 준비나 로그인 없이 작동했다. | 사용자 직접 확인. 외부 네트워크 요청 유무를 검사한 것은 아님. |
| 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있다 | Chrome 창의 가로 폭을 줄여 미분류 목록을 보고 가로로 스크롤했다. | 카드가 한 줄로 이어져 일부가 화면 밖으로 나갔지만, 가로 스크롤로 나머지 카드를 확인할 수 있었다. | 화면 밖으로 나가는 모습은 사용자 제공 스크린샷, 나머지 내용 접근은 사용자 직접 확인. ‘볼 수 있음’은 확인했으나 ‘오른쪽이 잘리지 않음’과는 차이가 있다. |
| ‘처음으로’를 누르면 처음 영화 8개가 모두 미분류로 돌아간다 | 기생충을 S칸으로 옮기고 ‘테스트 영화’를 추가한 뒤 ‘처음으로’를 눌렀다. | 최초 영화 8편만 모두 미분류에 남고, S·A·B·C칸은 비워졌다. 추가한 ‘테스트 영화’도 없어졌다. | 사용자 직접 확인. 초기화 동작 정상. |
| 영화가 한 칸에만 있고, 옮긴 칸에 남는다 | 미분류의 ‘테스트 영화’ 카드를 A칸으로 끌어 놓았다. | A칸으로 이동하고 미분류에서는 없어졌다. | 사용자 직접 확인. 이동 직후 A칸과 미분류 사이에 중복 없음. |
| 제목을 입력하면 새 영화 카드가 생긴다 | 제목에 ‘테스트 영화’를 입력하고 추가를 눌렀다. | 미분류에 ‘테스트 영화’ 카드가 생겼다. | 사용자 직접 확인. 제목 입력 후 추가 동작 정상. |
| 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남는다 | ‘테스트 영화’를 추가해 A칸으로 옮긴 다음 HTML 탭을 닫고 같은 파일을 다시 열었다. | 추가했던 ‘테스트 영화’ 카드가 사라졌다. | 사용자 직접 확인. 파일을 다시 열었을 때 추가 영화 유지 실패. |
| 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남는다 | 기생충 카드를 선택하고 S 글자를 누른 뒤 새로고침했다. | S칸으로 옮겼던 기생충이 새로고침 후 미분류로 돌아왔다. | 사용자 직접 확인. 새로고침 후 등급 유지 실패. 기존 영화의 탭 재열기는 아래의 추가 확인에 별도로 기록했다. |

## 받은 의견 확인 및 판단

위의 사전 기록을 남긴 다음 받은 피드백을 읽었다. 이후 추가 확인도 사용자가 직접 실행한 결과로 기록한다.

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
|---|---|---|---|
| AI: 저장 기능이 없어 다시 열면 미분류로 돌아간다 | 기생충을 S로 옮겨 새로고침하니 미분류로 돌아왔다. 추가한 ‘테스트 영화’는 탭을 닫고 같은 파일을 다시 열었을 때 사라졌다. 최종 점검에서 기생충도 S로 옮긴 뒤 탭을 닫고 같은 파일을 다시 여니 미분류로 돌아오는 것을 추가 확인했다. | 반영 | 영화와 등급이 유지되어야 한다는 완성 기준에 어긋난다. 다만 ‘모든 영화가 미분류로 돌아간다’는 표현은 추가 영화가 사라진 결과까지 포함하도록 보완해야 한다. 저장 코드 부재 자체는 실행 결과만으로 단정하지 않는다. |
| AI: ‘처음으로’가 직접 추가한 영화를 지우지 않는다 | 기생충을 S로 옮기고 ‘테스트 영화’를 추가한 뒤 초기화하니 추가 영화가 없어지고 최초 8편만 미분류에 남았다. | 보류 | 직접 확인한 결과와 반대다. 초기화는 기획서대로 동작했다. |
| AI: 빈 제목을 막지 않아 기획서를 어긴다 | 입력칸을 완전히 비우고 추가를 누르니 글자 없는 카드가 생겼다. | 반영 | 빈 카드가 생긴다는 현상은 맞다. 다만 기획서에 빈 제목 금지 조건은 없으므로 기획 위반이라는 설명은 받아들이지 않는다. 영화를 구별할 수 없는 사용상 불편으로 개선한다. |
| AI: 이 세 가지 외에는 완성 기준을 잘 지킨다 | 좁은 창에서 미분류 카드 줄이 화면 밖으로 나가고 가로 스크롤이 필요했다. 나머지 카드는 스크롤로 확인했다. | 보류 | 내용을 볼 수는 있지만 ‘오른쪽이 잘리지 않음’까지 충족한다고 단정할 수 없다. 좁은 폭에서 줄바꿈하도록 개선할 항목이 있다. |
| 동료: 등급마다 색이 달라 어느 칸인지 한눈에 들어온다 | 사용자 제공 화면에서 S는 붉은색, A는 주황색, B는 초록색으로 구분되는 모습을 확인했다. 클릭 이동 방법도 사용자는 헷갈리지 않았다고 답했다. | 반영 | 색과 등급 글자를 함께 보여 주는 구분을 유지한다. ‘한눈에 들어온다’는 느낌까지 객관적인 사실로 단정하지 않는다. |
| 동료: ‘8편 중 3편 나눔’ 표시로 얼마나 남았는지 알 수 있어 좋다 | 초기화 후 서로 다른 영화 3편을 등급 칸으로 옮기니 ‘8편 중 3편 나눔’이 표시됐다. | 반영 | 실제 분류 수와 표시가 일치한다. 분류 진행 정도를 알 수 있는 장점이므로 유지하고 최종 피드백의 잘된 점에 포함한다. |
| 동료: 드래그할 때 칸 색이 바뀌어 놓을 곳을 알 수 있다 | 카드를 끌어 등급 칸 위에서 놓지 않고 잠시 멈추니 해당 칸의 배경색이 바뀌었다. | 반영 | 사용자가 직접 확인했다. 놓을 위치를 알려 주는 장점이므로 유지한다. |
| 동료: 미분류가 맨 아래에 있어 S칸까지 끌어 올리기 불편하다. 목록을 위나 옆에 두면 좋겠다 | 미분류 목록에서 S칸으로 끌어 올릴 때 S칸이 화면 밖에 있어 스크롤이 필요했고, 드래그 중 자동 스크롤은 되지 않았다. | 반영 | 실제로 이동을 어렵게 하는 불편이 확인됐다. 영화 분류가 주된 목적이므로 개선한다. 목록 위치 변경은 한 가지 대안이며, 화면 밖 등급으로도 쉽게 옮길 수 있는 방식으로 검토한다. |
| 동료: 휴대폰으로 열면 좀 불편하다 | PC의 좁은 창에서는 가로 스크롤로 나머지를 볼 수 있었다. 실제 휴대폰에서는 시험하지 않았다. | 되묻기 | PC의 좁은 창 결과를 휴대폰 결과로 대신하지 않는다. 질문: 어떤 휴대폰·브라우저에서 어떤 행동을 할 때 무엇이 불편했나요? 화면 잘림, 터치 이동 등 재현할 장면을 알려 주세요. |
| 동료: 카드 옮기는 게 처음에는 헷갈렸다 | 사용자는 카드 선택 후 등급 글자를 눌러 옮겼고, 방법이 헷갈리지 않았다고 답했다. | 되묻기 | 내 경험만으로 동료의 경험을 부정할 수 없고, 어느 단계가 문제인지 불명확하다. 질문: 카드 선택, 등급 글자 누르기, 드래그 중 어느 단계에서 무엇을 예상했고 어떻게 동작했나요? |
| 동료: 카드 색이 칙칙하다 | 사용자 제공 화면에서 미분류 카드는 회색 계열이었다. 색 때문에 영화를 구분하지 못하거나 조작하지 못한 사례는 확인되지 않았다. | 보류 | 칙칙하다는 느낌은 취향이다. 구체적인 가독성 문제나 목적에 미치는 영향이 확인되면 다시 검토한다. |
| 동료: 영화 포스터 사진이 있으면 더 보기 좋겠다 | 제목 카드로 영화 추가와 이동을 완료했고, 제공 화면의 카드에는 포스터 대신 제목이 보였다. | 보류 | 포스터는 기획서의 필수 조건이 아니다. 외부 파일 없이 HTML 한 장으로 쓰는 조건도 고려해야 하므로, 우선 확인된 저장·이동 문제를 해결한다. |
| 동료: C칸은 없어도 된다 | 사용자는 S·A·B·C 구조의 페이지에서 영화 이동을 확인했다. C칸 삭제의 효과는 시험하지 않았다. | 보류 | 본 영화를 네 등급으로 나눠 취향을 정리하는 것이 기획 목적이다. 아쉬운 영화도 분류할 수 있어야 하므로 개인 선호만으로 C칸을 없애지 않는다. |
| 동료: 큰 문제가 없어 PASS | 새로고침 후 등급 초기화, 파일 재열기 후 추가 영화 소실을 확인했다. | 보류 | 잘 작동하는 기능이 있지만 저장 유지라는 명시적 완성 기준이 충족되지 않았다. 동료의 PASS를 그대로 따르지 않고 보완 후 다시 확인한다. |
| 직접 발견: 좁은 창에서 카드 줄이 화면 밖으로 나감 | 창 폭을 줄이니 일부 카드가 화면 밖에 있었고 가로 스크롤로 나머지를 확인했다. | 반영 | 스크롤로 접근은 가능해도 기획서의 ‘오른쪽이 잘리지 않음’과 차이가 있다. 좁은 창에서는 카드를 여러 줄로 배치하도록 제안한다. 실제 휴대폰 동작까지 확인했다는 뜻은 아니다. |

- 아무도 말하지 않았는데 내가 찾은 것: 추가한 ‘테스트 영화’는 같은 파일을 다시 열면 미분류로 돌아오는 것이 아니라 아예 사라졌다. AI가 말한 등급 초기화 외에 추가 영화 자체도 유지되지 않는다는 점을 확인했다. 저장 문제를 반영할 때 함께 해결해야 한다. 좁은 창에서 가로 스크롤이 필요한 현상도 사전에 확인했으나, 동료의 ‘휴대폰에서 불편’과 같은 문제를 뜻하는지는 아직 알 수 없다. 받은 의견을 추가 확인하면서, 미분류에서 화면 밖 S칸으로 드래그할 때 자동 스크롤이 되지 않는다는 구체적인 현상도 확인했다.
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: 새로고침과 파일을 닫았다가 다시 열기를 각각 확인해야 하는 이유. 확인한 동작의 범위를 정확히 적어 과장된 피드백을 피하고 싶다.
