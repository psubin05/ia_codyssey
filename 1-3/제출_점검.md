- [x] 불명확한 휴대폰·초기 혼란 의견은 되묻기로 정하고 질문을 적었다.

## 추가 확인하면 좋은 부분

- [x] 기존 영화의 파일 재열기도 추가 확인했다. 기생충을 S로 옮긴 뒤 탭을 닫고 같은 파일을 다시 열자 미분류로 돌아왔다. 추가 영화 소실과 기존 영화 등급 초기화를 모두 확인했고, 추가 확인 시점도 기록에 구분했다.
- 좁은 창은 스크린샷과 가로 스크롤로 확인했다. 정확한 창 폭·Chrome 버전은 측정하지 않았으므로 숫자를 만들어 적지 않았다. 평가 현장에서 같은 창 크기로 재현하거나 화면을 보여 줄 수 있다.
- 직접 해도 의미가 분명하지 않은 두 의견은 ‘되묻기’로 처리했다. 원래 피드백 작성자와 실제로 질문·답변을 주고받은 것은 아니다.

## 실제 제출·평가 상태

- [ ] 두 필수 파일을 Git에 커밋하고 GitHub에 업로드
- [ ] GitHub의 해당 폴더에서 파일 내용과 표가 보이는지 확인
- [ ] 운영 안내에 별도 제출란이 있다면 저장소 또는 폴더 링크 등록
- [ ] 실제 동료에게 평가받기
- [ ] 보완 요청이 있으면 수정 후 재평가받기

로컬 Git 확인 시 `1-3/`은 아직 추적되지 않은 새 폴더였다. GitHub 업로드 완료로 표시하지 않는다. 운영 사이트의 별도 제출 절차는 제공받지 않아 완료 여부를 확인하지 못했다. 좋은 평가나 PASS를 보장할 수는 없으며 실제 평가자의 확인이 필요하다.

## 선택 코랩 자료

[코랩세션리포트_양식.md](코랩세션리포트_양식.md)는 제공된 빈 양식을 복사한 참고 자료다. 실제 세션·동료평가 완료본이 아니다. 입학연수에서는 코랩 질문지가 필수가 아니므로, 세션을 하지 않았다면 작성 완료본처럼 제출할 필요가 없다. 양식의 7장 평가 체크는 실제 평가 동료가 수행한 뒤 표시해야 한다.

이번 과제는 피드백을 검증하고 다시 쓰는 과제다. HTML 수정본, 기획서 수정본, 대화 캡처는 제시된 필수 제출 파일에 포함되지 않는다.
