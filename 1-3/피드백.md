잘된 점: 화면에서 S·A·B칸이 서로 다른 색과 등급 글자로 구분되어 있었습니다. ‘테스트 영화’를 추가하니 미분류에 카드가 생겼고, A칸으로 끌어 놓으니 미분류에서 없어지고 A칸으로 이동했습니다. 서로 다른 영화 세 편을 분류했을 때 ‘8편 중 3편 나눔’이 표시되어 진행 정도를 알 수 있었습니다. 드래그 중에는 놓을 칸의 배경색이 바뀌었습니다. ‘처음으로’를 누르면 추가 영화가 없어지고 최초 8편이 모두 미분류로 돌아오는 것도 확인했습니다.

고치면 좋을 점

1. 본 것: 기생충을 선택해 S 글자를 누른 뒤 새로고침했더니 미분류로 돌아왔습니다. 기생충을 다시 S로 옮겨 탭을 닫고 같은 파일을 다시 열었을 때도 미분류로 돌아왔습니다. 또 ‘테스트 영화’를 추가해 A칸으로 옮긴 뒤 HTML 탭을 닫고 같은 파일을 다시 열었더니 추가한 카드가 사라졌습니다.

   기준: 기획서의 ‘같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다’.

   제안: 추가한 영화 목록과 각 영화의 등급이 함께 저장되고, 같은 파일을 다시 열면 복원되도록 해 주세요. 수정 후에는 기존 영화의 등급과 추가한 영화가 모두 유지되는지 확인하면 좋겠습니다.

2. 본 것: 제목 입력칸을 완전히 비우고 ‘추가’를 눌렀더니 글자 없는 카드가 생겼습니다.

   기준: 기획서에 빈 제목 금지 조건은 없지만, 쓰면서 어떤 영화인지 구별할 수 없는 점이 불편했습니다.

   제안: 제목이 비어 있으면 카드를 만들지 않고 ‘영화 제목을 입력해 주세요’라고 알려 주세요. 공백만 입력한 경우도 함께 막으면 좋겠습니다.

3. 본 것: 아래쪽 미분류 목록에서 화면 밖의 S칸까지 카드를 끌어 올리려니 위로 스크롤해야 했고, 드래그 중 자동 스크롤은 되지 않았습니다.

   기준: 쓰다가 불편했던 점입니다. 클릭 이동은 헷갈리지 않았지만, 기획서에서 제공하는 드래그 방식도 화면 밖 등급까지 사용하기 쉬우면 좋겠습니다.

   제안: 목록과 등급 칸을 함께 볼 수 있게 배치하거나, 카드를 화면 위쪽으로 끌면 자동으로 스크롤되게 해 주세요. 미분류에서 시작해 화면 밖 S칸까지 드래그로 옮길 수 있는지 확인하면 좋겠습니다.

4. 본 것: Chrome 창의 가로 폭을 줄였더니 미분류 카드가 한 줄로 이어져 오른쪽 카드가 화면 밖으로 나갔습니다. 가로 스크롤을 하면 나머지 카드를 볼 수 있었습니다.

   기준: 기획서의 ‘화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다’. 내용에 접근은 가능했지만 가로 스크롤이 필요했습니다.

   제안: 좁은 창에서는 영화 카드가 여러 줄로 배치되도록 해 주세요. 같은 폭에서 가로 스크롤 없이 모든 영화 제목을 볼 수 있는지 확인하면 좋겠습니다.
