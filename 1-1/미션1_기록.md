# 미션 1 기록

- AI A 이름 / 주요 대화 텍스트 파일명: Codex (OpenAI) / `codex 대화.md`. 정확한 모델명은 미확인.
- AI B 이름 / 주요 대화 텍스트 파일명: Gemini (Google) / `gemini 대화.md`. 정확한 모델명은 미확인.
- AI가 물어서 내가 정한 것:
  - 제공된 영화 8편을 사용하고, 제목만 있는 카드로 표시하기로 했다.
  - 마우스로 카드를 끌어 등급을 정하고, 다시 열어도 영화 목록과 배치를 유지하기로 했다.
  - 영화 추가와 초기화 기능을 넣고, 초기화 전에 확인창을 띄우기로 했다.
  - 어두운 영화관 느낌으로 꾸미기로 했다. 영화라는 주제와 연결되는 분위기를 만들고 카드와 등급에 시선이 모이도록 하되, 밝은 글자로 읽기 쉽게 한다는 이유를 문서화했다.
  - 처음에는 S·A·B·C·D를 정했지만, 두 AI 비교에 사용할 최종 기획서는 S·A·B·C와 미분류로 통일했다.
- 같은 행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과):

| 해본 행동 | 기대 결과 | A의 결과 | B의 결과 |
|---|---|---|---|
| 두 결과물 사용 후 편의성 비교 | 이어서 사용할 결과물 선택 | 사용자가 Codex 결과가 더 편했다고 평가함 | 사용자 선택은 A. B의 구체적인 불편 사항은 기록하지 않음 |
| 영화를 S칸으로 끌어올리기 | 화면 밖의 S칸까지 편하게 이동 | 사용자가 드래그 중 화면이 자동으로 올라가지 않아 불편하다고 보고함 | S칸으로 이동 가능함. 별도 자동 스크롤 개선은 적용하지 않음 |
| 새 영화 제목 추가 | 미분류에 새 카드 생성 | 기대 결과대로 동작함(사용자 확인) | 기대 결과대로 동작함(사용자 확인) |
| 공백만 입력 후 추가 | 카드가 생기지 않고 안내 표시 | 기대 결과대로 동작함(사용자 확인) | 기대 결과대로 동작함(사용자 확인) |
| 영화 이동·추가 후 같은 브라우저에서 같은 파일 다시 열기 | 배치와 추가 영화 유지 | 기대 결과대로 동작함(사용자 확인) | 기대 결과대로 동작함(사용자 확인) |
| 초기화 취소 후 확인 | 취소 시 유지, 확인 시 최초 8편이 미분류로 복귀 | 기대 결과대로 동작함(사용자 확인) | 기대 결과대로 동작함(사용자 확인) |

- 선택한 파일명과 고른 이유: `영화_A_초안.html`. 두 결과물 중 Codex가 만든 결과물이 더 편하다고 느껴 선택했다. 이후 자동 스크롤 개선을 반영한 `영화_A_수정1.html`을 이어서 사용한다.

| 파일명 | 고친 내용 | 고친 이유 | 다시 확인한 결과 |
|---|---|---|---|
| 영화_A_수정1.html | 카드를 잡고 화면 위·아래 가장자리로 이동하면 자동 스크롤. 가장자리에서 멀어지거나 드롭·드래그 종료·창 전환 시 스크롤 중단 | 미분류 영화를 화면 위쪽 S칸으로 옮길 때 화면이 자동으로 올라가지 않아 불편했음 | 사용자가 재확인함. 화면 위쪽 가장자리에서 자동으로 올라가 S칸에 놓을 수 있고, 가운데 이동·드롭 시 멈춤. 다시 열어도 배치 유지 |

- 고치지 않았다면 그대로 둔 이유: 해당 없음. A·B 초안은 비교 자료로 보존하고 별도 수정본을 만들었다.
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: 같은 기획서로 만든 두 결과물의 화면 구성과 드래그 편의성이 어떻게 달랐는지 이야기하고 싶다.

## 사용자 확인 결과

- 2026-11-10 사용자가 남은 확인을 완료했다고 알려 위 비교 결과와 수정본 재확인 결과를 반영했다.
- 실제 브라우저 확인은 사용자가 수행했으며, Codex의 자동 브라우저 검증 결과로 표시하지 않는다.
- 대화는 사용자 선택에 따라 `codex 대화.md`, `gemini 대화.md` 텍스트 기록으로 제출한다.
## 코드 수준 검증

- JavaScript 문법 검사 통과.
- 모의 드래그 이벤트로 위쪽 가장자리에서 위로, 아래쪽 가장자리에서 아래로 스크롤되는지 확인함.
- 화면 가운데 이동, 드롭, 드래그 종료, 창 포커스 해제 시 스크롤 중단을 확인함.
- 영화 드래그 중이 아닐 때는 자동 스크롤이 시작되지 않음을 확인함.
- 위 검증은 코드 수준 검증이며, 실제 브라우저 재확인은 사용자가 별도로 완료했다고 알림.
