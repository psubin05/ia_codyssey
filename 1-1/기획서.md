# 영화 티어리스트 기획서

## 누가 쓰나
- 영화를 좋아하는 사람들과 나

## 무엇을 하려고
- 본 영화들을 S·A·B·C 등급으로 나눈 티어리스트를 만들고 정리합니다.

## 화면과 동작
- 상단에는 S, A, B, C 등급 영역이 위치하고, 하단에는 '미분류' 영화 카드 영역이 위치합니다.
- 영화 카드를 마우스로 끌어서 놓는 드래그 앤 드롭 방식으로 원하는 등급 칸이나 미분류 칸으로 옮깁니다.
- 새 영화 제목을 입력하고 추가할 수 있는 기능이 있습니다.
- 브라우저를 새로고침하거나 다시 열어도 옮겨둔 등급 배치와 추가한 영화가 그대로 남아있습니다.
- '초기화' 버튼을 누르면 브라우저에 저장된 배치가 지워지고 처음 상태로 돌아갑니다.

## 필요한 자료
- 기본 영화 8개: 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리

## 완성 기준
- 영화 카드를 마우스 드래그 앤 드롭으로 S, A, B, C 및 미분류 칸으로 옮길 수 있습니다.
- 새 영화 제목을 입력해 추가하면 미분류 칸에 카드가 생성됩니다.
- 영화를 S칸으로 옮기고 브라우저를 다시 열어도 S칸에 그대로 남아있습니다.
- '초기화' 버튼을 누르면 기본 8개 영화가 모두 미분류 칸으로 돌아갑니다.
- 빈칸이나 공백만 입력하고 추가를 누르면 카드가 생기지 않고 입력 안내 메시지가 나옵니다.
- 외부 서버, 회원가입, 외부 파일 없이 브라우저에서 HTML 파일 하나로 바로 열립니다.
