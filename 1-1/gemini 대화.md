# Gemini 대화 기록

## 1. 영화 티어리스트 기획 질문
- **사용자**: 영화 티어리스트 웹페이지를 만들고 싶어. 아직 만들지 말고 필요한 것부터 질문해 줘. 누가 쓰는지, 목적, 화면과 동작, 필요한 자료, 완성 기준을 정하고 싶어. 한 번에 서너 개씩만 물어봐 줘.
- **Gemini (1차 질문)**: 
  1. 사용자 및 등급 설정 (누가 쓰는지, 등급 방식)
  2. 영화를 옮기는 방식 (드래그 앤 드롭 vs 버튼/클릭)
  3. 저장 기능 (새로고침/재방문 시 배치 유지 여부)
- **사용자 답변**:
  1. 영화를 좋아하는 사람들이 등급을 나누는데 씀. 등급은 S, A, B, C로 구분.
  2. 마우스로 끌어서 놓는 드래그 앤 드롭 방식.
  3. 새로고침 후에도 남아있어야 함.

- **Gemini (2차 질문)**:
  1. 기본 영화 목록(아이디어.md의 8개) 표시 및 새 영화 추가 기능 포함 여부
  2. 초기화 버튼 필요 여부
- **사용자 답변**:
  1. 기존 8개 영화 유지하고 처음에 미분류 상태로 표시.
  2. 새로고침 시 배치가 유지되므로 초기화 버튼 필수 필요.

## 2. 기획서 작성
- **사용자**: (위 내용을 정리하여 마크다운 기획서 작성 요청)
- **Gemini**: 대화 내용을 바탕으로 `기획서.md` 작성 및 전달.
  - 항목: 누가 쓰나 / 무엇을 하려고 / 화면과 동작 / 필요한 자료 / 완성 기준
  - 추가 제안 기능(회원가입, 서버 저장 등) 제외하고 단일 HTML 실행 조건 반영.

## 3. HTML 파일 제작
- **사용자**: 기획서대로 html 만들어줘
- **Gemini**: `영화_A_초안.html` 생성 및 전달.
  - S·A·B·C 및 미분류 칸 구성.
  - 마우스 드래그 앤 드롭 이동 기능 구현.
  - LocalStorage 기반 실시간 자동 저장 기능 구현.
  - 공백 영화 추가 방지 예외 처리 및 알림창 구현.
  - '초기화' 버튼 클릭 시 기본 8개 미분류 상태 복원 로직 포함.
