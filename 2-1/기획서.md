# 포근한 하루 — 하루 일정 관리

## 대상 사용자

- 일정 관리가 익숙하지 않아 오늘 해야 할 일을 놓치거나 우선순위를 정하기 어려운 사람.
- 우선 컴퓨터의 웹 브라우저에서 사용한다.

## 사용 목적

- 오늘 해야 할 일을 가장 먼저 확인하고, 중요도가 높은 일부터 처리한다.
- 월별 달력으로 날짜별 할 일을 확인하고 완료 여부를 관리한다.

## 화면 구성과 동작

### 화면과 분위기

- 크림색 배경과 연한 살구색 포인트, 갈색 글자, 둥근 모서리를 사용해 포근한 느낌을 준다. 본문과 배경은 읽기 쉽게 구분한다.
- 맨 위에는 페이지 이름과 오늘 날짜, 가장 눈에 띄는 ‘오늘 할 일’ 영역을 배치한다.
- 오늘 할 일 아래에는 ‘지난 미완료’ 영역을 두어 예정일이 지났지만 끝내지 못한 일을 보여 준다. 해당 항목이 없으면 ‘지난 미완료 일정이 없습니다’를 표시한다.
- 아래에는 월별 달력과 선택한 날짜의 전체 할 일 목록을 배치한다. 처음 열면 오늘 날짜를 선택한다.
- 이전 달·다음 달 버튼으로 월을 이동하고, ‘오늘’ 버튼으로 현재 월과 오늘 날짜로 돌아온다.
- 달력의 각 날짜 칸에는 할 일 제목을 짧게 표시한다. 많으면 최대 3개와 ‘외 N개’를 표시하고, 날짜를 누르면 선택 날짜 목록에서 전체 제목과 내용을 확인한다.
- 목록에는 제목, 예정일, 마감 시간, 별 중요도, 완료 체크, 수정·삭제 버튼을 표시한다. 일정이 없으면 ‘등록된 할 일이 없습니다’를 표시한다.

### 입력과 관리

- 할 일 추가 시 제목, 예정일, 중요도는 필수이고 마감 시간은 선택 사항이다. 예정일은 기본적으로 선택한 날짜, 중요도는 기본 별 3개로 설정한다.
- 중요도는 별 1~5개로 선택한다. 별이 많을수록 중요하며, ‘중요도 4/5’처럼 숫자도 함께 표시한다.
- 날짜는 할 일을 할 일자이고, 마감 시간은 그 날짜 안에서 일을 끝내야 하는 시각이다. 마감 시간은 24시간 형식으로 입력한다.
- 제목이 비어 있거나 날짜·시간이 유효하지 않으면 저장하지 않고 입력 안내를 표시한다.
- 저장하면 해당 날짜의 목록과 달력에 반영한다. 오늘 일정이라면 오늘 할 일 영역에도 반영한다.
- 수정 버튼으로 제목·예정일·마감 시간·중요도를 변경한다. 삭제 버튼을 누르면 확인 창을 띄우며, 취소하면 유지하고 확인하면 삭제한다.

### 정렬과 완료 처리

- 각 목록에서 미완료 항목을 먼저 표시하고, 중요도가 높은 순서로 정렬한다.
- 중요도가 같으면 마감 시간이 빠른 순서로 표시하고, 마감 시간이 없는 항목은 그 중요도 그룹의 뒤에 둔다. 조건이 모두 같으면 먼저 등록한 순서로 표시한다.
- ‘지난 미완료’처럼 여러 날짜가 섞인 목록에서는 중요도가 같을 때 예정일과 마감 시간을 합친 마감 시점이 빠른 순으로 정렬한다. 시간이 없는 항목의 마감 시점은 해당 날짜의 끝으로 본다.
- 완료 체크를 하면 취소선을 표시하고 그 목록의 모든 미완료 항목 아래로 이동한다. 완료 항목끼리는 먼저 등록한 순서로 표시한다.
- 완료 체크를 해제하면 미완료 정렬 기준에 맞는 위치로 돌아온다.
- 지난 미완료 항목을 완료하면 ‘지난 미완료’ 영역에서는 사라지며, 원래 예정일의 목록에서 완료 상태로 확인할 수 있다.

### 마감과 저장

- 입력한 마감 시각이 지난 미완료 항목에 ‘마감 지남’을 표시한다. 마감 시간이 없으면 해당 날짜가 끝나 다음 날이 되는 순간부터 표시한다. 완료 항목에는 표시하지 않는다.
- 날짜와 마감 판단은 사용자 컴퓨터의 현지 날짜·시간을 기준으로 한다. 페이지를 열거나 다시 활성화할 때, 그리고 열려 있는 동안 매분 날짜와 마감 표시를 갱신한다.
- 추가·수정·삭제·완료 상태를 브라우저의 로컬 저장소에 저장한다. 같은 컴퓨터·같은 브라우저에서 같은 HTML 파일을 다시 열면 복원한다.
- 저장할 수 없는 환경에서는 ‘일정을 저장할 수 없습니다. 브라우저 저장 설정을 확인해 주세요’를 표시해 저장 실패를 알린다.

## 필수 기능

- 오늘 할 일과 지난 미완료 일정 표시.
- 월별 달력 이동, 오늘로 돌아가기, 날짜별 목록 확인.
- 제목·예정일·선택 마감 시간·별 1~5개 중요도를 입력해 일정 추가.
- 일정 수정·삭제와 삭제 확인.
- 중요도·마감 시점에 따른 정렬, 완료 체크와 완료 항목의 아래 이동.
- 마감이 지난 미완료 일정 표시.
- 브라우저 로컬 저장소를 통한 일정과 완료 상태 유지, 저장 실패 안내.

## 필요한 자료

- 사용자가 직접 입력하는 할 일 제목, 예정일, 선택 마감 시간, 중요도, 완료 상태. 실제 개인정보나 일정은 기본 예시에 넣지 않는다.
- 화면 안내 문구와 검증용 가상 일정은 직접 작성한다. 외부 글을 인용하지 않는다.
- 별은 텍스트 기호(★·☆)로 표시하고, 글꼴은 컴퓨터에 설치된 기본 시스템 글꼴을 사용한다.
- 외부 사진·글꼴·라이브러리를 사용하지 않으므로 별도의 외부 자료 출처나 사용 허가가 필요하지 않다.
- 달력과 오늘 날짜는 컴퓨터의 날짜 정보를 사용하며 외부 API를 호출하지 않는다.

## 완료 기준

- 별도 파일·로그인·API 키·서버 없이 HTML 파일 하나를 컴퓨터 브라우저에서 열 수 있고, 인터넷 연결 없이도 필수 기능이 동작한다.
- 처음 열면 오늘 날짜가 선택되고, 오늘 할 일이 화면 상단에 표시된다. 일정이 없으면 빈 상태 안내가 보인다.
- 할 일 제목·예정일·중요도를 입력해 저장하면 해당 날짜의 달력과 목록에 나타난다. 마감 시간을 비워도 저장된다.
- 빈 제목이나 잘못된 날짜·시간으로 저장하려 하면 안내가 표시되고 일정은 추가되지 않는다.
- 같은 날짜에 별 5개, 별 3개, 별 1개인 미완료 일정을 등록하면 별 5개부터 표시된다.
- 같은 날짜·같은 중요도인 일정은 09:00, 18:00, 마감 시간 없음 순으로 표시된다. 조건이 모두 같으면 등록 순서를 유지한다.
- 완료 체크를 하면 취소선이 생기고 모든 미완료 항목 아래로 이동한다. 체크를 해제하면 원래 정렬 규칙에 맞게 돌아온다.
- 달력에서 다른 날짜를 누르면 그 날짜의 전체 일정이 표시된다. 이전 달·다음 달·오늘 버튼이 각각 해당 월이나 오늘 날짜로 이동한다.
- 일정이 4개 이상인 날짜는 달력 칸에 제목 최대 3개와 나머지 개수가 표시되며, 날짜를 선택하면 전체 목록을 확인할 수 있다.
- 어제의 미완료 일정은 ‘지난 미완료’에 표시된다. 완료하면 해당 영역에서 사라지고 어제 날짜의 목록에는 완료 상태로 남는다.
- 오늘의 마감 시간이 지난 미완료 항목에는 ‘마감 지남’이 표시된다. 마감 시간이 없는 오늘 일정에는 오늘 중 표시되지 않고, 다음 날부터 표시된다.
- 제목·날짜·시간·중요도를 수정하면 관련 목록과 달력에 반영된다. 삭제 확인을 취소하면 유지되고, 확인하면 삭제된다.
- 저장 후 새로고침하거나 같은 브라우저에서 같은 파일을 닫았다 다시 열면 일정과 완료 상태가 유지되며, 삭제한 일정은 복원되지 않는다.
- 컴퓨터의 1280×720 화면과 브라우저 배율 100%에서 가로 스크롤 없이 주요 내용을 읽고 버튼을 사용할 수 있다. 세로 스크롤은 허용한다.

## 추가 기능

- 휴대폰의 좁은 화면에 맞춘 화면 배치와 터치 조작 개선.
- 추가 기능은 후속 확장 범위이며, 이번 컴퓨터용 HTML의 완료 여부를 판단하는 필수 조건에는 포함하지 않는다.

## 한계 및 비목표

1. 로그인·서버·클라우드 동기화·외부 캘린더 연동을 구현하지 않는다. 일정은 같은 기기·같은 브라우저의 저장소에만 남으며, 저장소 삭제·시크릿 모드 종료·파일 경로 변경 등에 따라 유지되지 않을 수 있다. 장기 백업은 보장하지 않는다.
2. 반복 일정·알림 전송·챗봇·AI 일정 추천은 구현하지 않는다. 날짜와 마감 판단은 컴퓨터 시계에 의존하며, 별도의 실제 시각 검증은 하지 않는다.
3. 이번에는 컴퓨터용 화면을 우선 구현한다. 휴대폰 전용 화면 최적화는 추가 기능이며, 이번 완료 기준에 포함하지 않는다.

## 검증 방법

- **수기 기대 결과표와 화면·저장 결과 대조:** 컴퓨터 달력과 시계로 오늘 날짜 및 현재 시각을 확인하고, 아래 가상 일정을 등록한다. 시험 전 예상 정렬·마감 표시·완료 상태를 메모장에 적은 뒤 화면과 항목별로 비교한다. 마감 시각은 현재 시각보다 이전과 이후로 각각 정하되, 자정 근처라 두 시각을 같은 날에 만들 수 없으면 낮 시간에 검사한다.

| 가상 일정 | 예정일 | 중요도 | 마감 시간 | 최초 기대 결과 |
| --- | --- | --- | --- | --- |
| A | 오늘 | 별 5개 | 없음 | 오늘 목록 1번째, 마감 표시 없음 |
| B | 오늘 | 별 3개 | 현재보다 이전 | 오늘 목록 2번째, 마감 지남 |
| C | 오늘 | 별 3개 | 현재보다 이후 | 오늘 목록 3번째, 마감 표시 없음 |
| D | 오늘 | 별 3개 | 없음 | 오늘 목록 4번째, 마감 표시 없음 |
| E | 어제 | 별 1개 | 없음 | 지난 미완료에 표시, 마감 지남 |

- A를 완료 체크하면 오늘 목록이 B→C→D→A가 되는지, 해제하면 A→B→C→D로 돌아오는지 비교한다. E를 완료하면 지난 미완료에서 사라지고 어제 목록에는 남는지 확인한다. 이후 B의 제목을 수정하고 C를 삭제한 뒤 파일을 닫았다 다시 열어, 메모해 둔 최종 제목·항목 수·완료 상태와 대조한다. 서로 다르면 오류로 기록한다. 이 절차는 HTML 구현 후 실행한다.

## 사용한 AI 서비스와 모델 이름

- AI 서비스: OpenAI Codex
- 모델 이름: GPT-6 (현재 대화에 제공된 모델 정보 기준)
- 활용 내용: 사용자와의 질의응답으로 대상 사용자, 목적, 화면 구성, 일정 입력과 정렬 규칙을 구체화하고 기획서 초안을 작성했다.
- 사용자 답변 반영: 중요도를 별 1~5개로 변경하고, 날짜와 선택 마감 시간을 구분했으며, 완료 항목을 목록 아래로 이동하고 컴퓨터용 화면을 우선 구현하도록 정리했다.
- 제출 전 검토: 사용자가 완료 기준·한계 및 비목표·검증 방법이 의도와 맞는지 확인하고, 실제 사용 화면에 다른 모델명이 표시된다면 모델 이름을 그 표기에 맞춰 수정한다.
