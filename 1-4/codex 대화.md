# 미션 4 주요 대화 기록

- 사용 AI: Codex (OpenAI)
- 모델명: GPT-6.` Sol Light (사용자 제공 표기 그대로 기록)
- 기록 형식: 사용자 요청에 따른 Markdown 대화 기록
- 범위: 현재 대화에서 미션 4 제작과 확인에 관련된 주요 요청 및 답변. 전체 대화 내보내기나 화면 캡처는 아니며, AI 답변은 아래에서 요약으로 표시했다. 도구 실행 로그와 일부 진행 안내는 생략했다.

## 1. 미션 자료 확인

**사용자 요청 요약**

미션 4의 진행 순서·제출 요구사항과 세 파일을 제공하고, 읽어 보고 시작하라고 요청했다. 기획서와 HTML은 예시라고 설명했다.

**AI 답변 요약**

코랩 리포트, 예시 기획서, 원본 HTML을 읽었다. 기능 하나 추가, 기존 기능 재확인, 기존 기능 손상 시 원본 복귀, 버전별 파일 보존을 핵심 절차로 정리했다. 이 시점에는 브라우저 검증이나 파일 수정을 하지 않았다.

## 2. 원본과 추가 기능 선택

**사용자**

> 이거를 원본으로 쓰고. 내가 추가하고 싶은 기능은 제목으로 영화 찾기야

**첨부 자료**

- 제공된 `영화_원본.html`
- 앞서 읽은 예시 `기획서.md`

**AI 답변 및 작업 요약**

원본을 보존하고 제목 검색 기능을 추가하기로 했다. 기획서에 부분 제목 검색, 영문 대소문자 및 앞뒤 공백 처리, 결과 개수·결과 없음 안내, 검색 지우기, 검색 중 이동·추가, 초기화 시 검색 해제 기준을 먼저 덧붙였다. 이후 `영화_기능추가.html`과 `미션4_기록.md` 초안을 만들었다.

## 3. 파일 위치 정정

**사용자**

> 1-4로 다른것처럼 만들어야지 왜 따로 만드니?

**AI 답변 및 작업 요약**

저장 위치를 잘못 잡았음을 인정했다. 기존 과제 폴더 구조를 확인하고 작업 파일을 `ia_codyssey/1-4`로 옮겼다. 별도로 만들었던 폴더는 남기지 않았다. 제출 점검표와 선택 자료인 코랩 리포트 빈 양식도 보관했다.

## 4. 구현과 AI 검사

**AI 작업 결과 요약**

- 제목 일부가 포함된 영화만 모든 등급과 미분류에서 표시한다.
- 검색 결과 개수와 결과 없음 안내를 표시한다.
- 검색어를 지우면 전체 카드를 표시한다.
- 원본 파일은 제공 파일과 SHA-256이 일치했다.
- 모의 DOM 검사에서 초기 8편, 부분 검색, 검색 중 이동·저장 호출, 결과 없음, 검색 해제, 추가, 대소문자·공백 처리, 빈 제목 방지, 초기화가 통과했다.
- AI가 실제 브라우저의 드래그, 재열기 후 저장 유지, 좁은 화면 배치를 직접 검증한 것은 아니라고 알렸다.

검사 실행 중 샌드박스의 Node 파일 접근 제한이 있었고, 검증 코드의 모의 입력 요소 생성도 보완했다. 이는 검사 환경·검사 코드 보완이며 받은 HTML을 수정한 이력은 아니다. 기능추가 HTML은 한 버전만 생성했다.

## 5. 사용자 확인 완료

**사용자**

> 내가 확인했어

**AI 답변 및 작업 요약**

사용자의 브라우저 확인 완료 보고를 미션 기록과 제출 점검표에 반영했다. 완성본을 `영화_기능추가.html`로 표시했다. 개별 항목별 실행 내역이나 화면 캡처를 전달받은 것으로 기록하지 않았다.

## 6. 제출 요구사항 재점검

**사용자**

> 다 점검했니? 꼼꼼하게 확인해

사용자는 기획서, 받은 HTML 파일 전부, 미션 기록, 대화 캡처 이미지의 제출 요구 표를 함께 제공했다.

**AI 답변 및 점검 요약**

실제 파일을 열어 제출 요구와 대조했다. 기획서에 검색 기준이 추가돼 있고, 받은 HTML 한 버전이 보존돼 있으며, 기록에 완성본이 표시돼 있음을 확인했다. 대화 캡처 이미지가 없고, 기능 추가 전 원본의 직접 점검 기록이 없다는 점을 알렸다. 모델명은 화면에 보일 때 함께 적는 항목이므로 필수 누락과 구분했다.

## 7. 모델명 및 대화 기록 형식 지정

**사용자 요청 요약**

모델명을 “GPT-6.` Sol Light”라고 알려 주고, 대화 내용을 AI가 Markdown 파일로 정리하라고 요청했다.

**AI 작업 요약**

사용자 제공 모델명을 기록하고 이 파일을 작성했다. Markdown 기록은 과제 안내의 대화 캡처 이미지와 다른 형식이므로, 이미지 제출 요건 충족 여부는 별도로 남겼다.

## 확인 범위와 남은 사항

- 최종 HTML: `영화_기능추가.html`
- 사용자 브라우저 확인 완료 보고와 AI 모의 검사 결과를 구분했다.
- 기능 추가 전 원본을 직접 확인했다는 보고는 현재 대화에서 확인되지 않는다. 이후 확인으로 사전 점검을 수행한 것처럼 기록하지 않는다.
- 기존 기능 손상이나 추가 오류는 보고되지 않아 수정1 생성 및 원본 복귀는 진행하지 않았다.
- 실제 코랩 세션이나 동료평가는 수행한 것으로 기록하지 않는다.
- 이 파일은 사용자 선택에 따른 대화 기록이다. 과제 안내에서 요구한 캡처 이미지의 대체 허용 여부는 확인되지 않았다.

## 8. 외부 AI 평가 후 문서 보완

**사용자 요청 요약**

외부 AI의 7개 항목 평가를 전달했다. 해시·저장 위치, 검증 절차, 두 파일 첨부 안내, 파일 시각, 수정 버전 및 원본 복귀 절차 보완을 요구하는 내용이었다.

**AI 답변 및 작업 요약**

원본 해시와 파일 시각을 실제 조회해 보관 근거를 추가하고, 기획서에 기준별 검증 절차를 보완했다. 두 파일 첨부 안내는 사후 재사용 문구로 표시하고 실제 과거 대화와 구분했다. 수정본 생성과 원본 복귀는 과제의 조건부 절차이므로 오류가 없었던 상황에서 이력을 임의로 만들지 않았다. 오류 유형에 따른 수정·중단·원본 복귀·새 대화 절차를 문서화했다. HTML은 변경하지 않았다.
