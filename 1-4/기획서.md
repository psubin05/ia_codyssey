# 내 영화 티어리스트

## 누가 쓰나

- 나와 영화를 좋아하는 친구들

## 무엇을 하려고

- 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리합니다.

## 화면과 동작

- 위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드를 보여 줍니다.
- 카드를 누르고 등급 글자를 누르거나, 카드를 끌어 놓으면 해당 칸으로 옮겨집니다.
- 제목을 입력하고 ‘추가’를 누르면 아직 안 정한 영화에 카드가 생깁니다.
- 영화 목록과 등급 배치를 브라우저에 자동으로 저장합니다.
- ‘처음으로’를 누르면 처음 영화 목록과 배치로 돌아갑니다.

## 필요한 자료

- 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리

## 완성 기준

- 영화가 한 칸에만 있고, 옮긴 칸에 남습니다.
- 제목을 입력하면 새 영화 카드가 생깁니다.
- 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.
- 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.
- ‘처음으로’를 누르면 처음 영화 8개가 모두 미분류로 돌아갑니다.
- 외부 파일·로그인·서버 실행 없이 HTML 한 장으로 열립니다.
- 빈 제목은 추가하지 않습니다.

## 추가 기능: 제목으로 영화 찾기

- 제목 일부를 입력하면 모든 등급과 미분류에서 일치하는 카드만 보입니다.
- 영문 대소문자를 구분하지 않고 검색어 앞뒤 공백은 무시합니다.
- 검색 결과 개수를 표시하고, 결과가 없으면 안내합니다.
- 검색어를 지우거나 ‘검색 지우기’를 누르면 전체 카드가 다시 보입니다.
- 검색 중에도 클릭과 끌어 놓기로 영화를 이동할 수 있고 등급이 저장됩니다.
- 검색은 목록과 등급을 바꾸지 않습니다. 새 영화는 검색어와 일치할 때만 보입니다.
- ‘처음으로’를 누르면 검색어도 지워지고 처음 영화 8개가 미분류에 보입니다.

## 완성 기준별 검증 절차

아래는 평가 피드백 후 보완한 재현 절차이며, 각 절차를 실제 수행한 실행 로그를 뜻하지 않습니다. 테스트 제목이 남지 않도록 마지막에 ‘처음으로’를 누릅니다.

| 완성 기준 | 간단 검증 절차 |
|---|---|
| 한 칸에만 존재·이동 유지 | 기생충을 선택해 S를 누른 뒤 A로 끌어 놓고, A에만 한 장 있는지 확인합니다. |
| 영화 추가 | ‘테스트 영화’를 추가해 미분류에 한 장 생기는지 확인합니다. |
| 재열기 후 저장 | 기생충을 S로 옮기고 영화를 추가한 뒤, 같은 파일의 탭을 닫고 다시 열어 목록과 등급을 확인합니다. |
| 좁은 화면 표시 | 브라우저 폭을 320px 수준으로 줄여 오른쪽 잘림 없이 카드·입력·버튼을 볼 수 있는지 확인합니다. |
| 초기화 | 이동과 추가 후 ‘처음으로’를 눌러 원래 8편만 미분류에 남는지 확인합니다. |
| HTML 단독 실행 | 서버 없이 파일을 직접 열고 외부 자료·로그인 없이 조작되는지 확인합니다. |
| 빈 제목 방지 | 빈 입력과 공백만 입력한 상태에서 각각 ‘추가’를 눌러 카드가 늘지 않는지 확인합니다. |
| 전체 등급에서 부분 제목 검색 | 초기화 후 기생충을 S로 옮겨 ‘기생’을 검색하면 S의 기생충만 보이는지 확인합니다. |
| 대소문자·앞뒤 공백 | ‘Test Movie’를 추가하고 ‘  TEST movie  ’로 검색해 한 장이 나오는지 확인합니다. |
| 결과 개수·결과 없음 안내 | ‘기생’ 검색 시 1개, ‘없는제목123’ 검색 시 결과 없음 안내를 확인합니다. |
| 검색 해제 | 검색어를 직접 지우는 경우와 ‘검색 지우기’를 누르는 경우 모두 전체 카드가 보이는지 확인합니다. |
| 검색 중 이동·저장 | ‘기생’ 검색 중 클릭으로 A, 끌어 놓기로 B에 옮긴 뒤 재열기하여 B에만 남는지 확인합니다. |
| 검색 시 목록·등급 보존 및 추가 | 검색 전후 목록을 비교하고, ‘기생’ 검색 중 ‘기생충2’와 ‘괴물’을 추가해 전자만 보이다가 검색 해제 시 둘 다 보이는지 확인합니다. |
| 검색 중 초기화 | 검색어가 있는 상태에서 ‘처음으로’를 눌러 검색창이 비고 원래 8편이 모두 미분류에 보이는지 확인합니다. |
