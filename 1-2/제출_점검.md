## 제출 전 남은 사항

- 실제 브라우저에서 원본과 최종 수정본의 영화 8편 전체 및 추가 제목을 클릭·드래그로 비교하고 `미션2_기록.md`에 결과를 반영한다. 최종본을 처음 열 때 ‘처음으로’를 먼저 누른다.
- 저장 유지, 초기화, 공백 입력, 좁은 화면도 직접 확인한다.
- 사용자 선택으로 캡처 이미지는 만들지 않았다. 과제 안내는 대화 캡처 이미지를 요구하므로 Markdown 대체가 허용되는지는 운영 기준 확인이 필요하다.
- 코랩 세션 질문지는 입학연수에서 선택 사항이다. 실제 동료 세션·평가는 진행한 뒤에만 작성한다.
- GitHub 업로드는 아직 수행하지 않았다. 업로드 시 수정1·수정2·기록·대화 파일을 포함한다.

현재 파일 구성은 준비되었지만, 직접 검증 결과 반영과 GitHub 등록까지 완료된 제출 상태는 아니다.
